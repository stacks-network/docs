# Whitelisted Pool Operators

[Whitelisted pool operators](../glossary.md#whitelist-and-whitelist-row) manage the [community tranche](../glossary.md#community-tranche-10), expected to be roughly 10% of paired BTC capacity in PoX-5. They register [reward addresses](../glossary.md#reward-address), enroll members, lock pooled [sBTC](../glossary.md#sbtc) and STX, receive pool-level rewards, and distribute those rewards pro-rata.
