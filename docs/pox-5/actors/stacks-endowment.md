# Stacks Endowment

The [Stacks Endowment](../glossary.md#endowment-stacks-endowment) operates the [PoX-5 program](../glossary.md#bootstrap-phase-pox-5). It sets or approves each [bonding period](../glossary.md#bonding-period)'s capacity, [target APY](../glossary.md#apy-target), [static STX ratio](../glossary.md#static-stx-btc-ratio), partner [whitelist](../glossary.md#whitelist-and-whitelist-row), and pool [envelopes](../glossary.md#btc-capacity-envelope-pool) before the period opens.
