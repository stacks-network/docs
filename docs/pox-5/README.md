# Overview

Bitcoin earns nothing sitting still, and most ways to put it to work mean giving up custody. PoX-5 is the Stacks upgrade that enables Bitcoin Staking: BTC-denominated yield on bitcoin that never leaves your own keys, paid out of the revenue miners already spend competing for Stacks blocks. These docs cover how it works and how to build against it, including the [PoX-5](glossary.md#pox-pox-4-pox-5-pox-6) managed [bootstrap](glossary.md#bootstrap-phase-pox-5) phase of [Bitcoin Staking](glossary.md#bitcoin-staking): who participates, how implementation paths line up, and technical surfaces on the contract side.
