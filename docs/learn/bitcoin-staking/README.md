# Bitcoin Staking

Bitcoin Staking is the PoX-5 model for earning Bitcoin-denominated yield on Stacks. Participants either pair a Bitcoin commitment with locked STX in a protocol bond, or lock STX alone and earn the residual.

This section is being built out. Two pages are available now:

* [Glossary](glossary.md) — the vocabulary used across the Bitcoin Staking docs.
* [Rewards and tranches](rewards-and-tranches.md) — how miner Bitcoin revenue is distributed.

For the conceptual overview of staking and how it relates to signing, see [Staking: How STX Holders Contribute](../block-production/staking.md).
